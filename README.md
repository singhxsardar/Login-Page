## 🚀 About The Project

**Login Page** is a simple and modern authentication UI project designed with a clean layout and user-friendly interface.

The project focuses on creating a visually attractive login experience using core front-end technologies without any external framework.

---

## ✨ Features

* 🔐 Modern login interface
* 🎨 Clean and attractive UI
* 📱 Responsive design
* 🖥️ Desktop-friendly layout
* 🧩 Simple and structured HTML
* 🎯 Custom CSS styling
* ⚡ Lightweight and fast
* 🌐 Deployed on Netlify

```bash

```
